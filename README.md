# 🗂️ Мои проекты

Портфолио конфигураций на платформе **1С:Предприятие 8.3**.

Оба проекта — самописные, разработаны с нуля с продуманной архитектурой

## 💇 Конфигурация для салона красоты

### 📋 О проекте

MVP-версия конфигурации для автоматизации салона красоты: оперативный и регламентированый учёт, 
аналитические отчёты, права доступа, контроль остатков, расчет себестоимости. Разработана с нуля — 
не на базе типовой, а с собственной архитектурой метаданных.

### ✨ Что реализовано

**Оперативный учёт**
- Продажи услуг и товаров
- Движение денежных средств, кассы
- Складской учёт: поступление и списание материалов
- Контроль остатков

**Подсистемы БСП**
- Внедрены СтандартныеПодсистемы
- Настроены роли и права доступа
- Настроено версионирование объектов

**Аналитические отчёты (на СКД)**
- Продажи за период
- Финансовый результат
- Остатки на складах
- Движение денег в кассах
- Оптимизированные запросы: виртуальные таблицы, соединения

**Загрузка цен из Excel**
- Автоматизация загрузки прайс-листа в регистр сведений
- Валидация входных данных
- Информативный вывод ошибок пользователю
- ⚡ Сокращение времени загрузки **с нескольких часов до 10–15 минут**

**Печатные формы**
- Внешняя печатная форма для документа «Реализация»
- Учтены обязательные реквизиты и подписи
- Вывод дополнительных данных в макет

## 🐩 Конфигурация для груминг-салона

### 📋 О проекте

**Развитие конфигурации салона красоты.** Включает весь функционал первой версии 
и расширена новыми функциями: планировщик, дашборд руководителя, 
интеграция с внешним API, сложные периодические расчёты, бизнес-процессы.

### ✨ Базовый функционал (как в «Салоне красоты»)

- Оперативный и регламентированный учёт
- Подсистемы БСП, права доступа, версионирование
- Отчёты на СКД: по оказанным услугам, по товарам на складах, бухгалтерские отчеты, по движению наличных и безналичных средств, по начислению зарплаты
- Автозагрузка цен из Excel в регистр сведений
- Внешняя печатная форма для РТУ

### 🆕 Дополнительно в груминге

**Планировщик и аналитика**
- **Планировщик** — наглядное расписание мастеров
- **Дашборд для руководителя** — ключевые показатели на одном экране

**Интеграции**
- **Интеграция с API ЦБ РФ** — автоматическая загрузка курсов валют

**Сложные расчёты**
- Использование регистров расчета для начисления:
  - оклада
  - больничных
  - премий


**Бизнес-процессы**
- **Бизнес-процесс «Дорегистрация клиента»**
- Заменяет ручную передачу заявок через мессенджеры
- Автоматическое распределение задач между сотрудниками
- 📉 Снижение нагрузки на **20%**, ускорение обработки заявок

## 🚀 Как развернуть любую из конфигураций

1. Создайте пустую информационную базу в 1С:Предприятие 8.3.
2. Откройте её в режиме **Конфигуратор**.
3. Меню: `Администрирование → Загрузить информационную базу...`
4. Выберите соответствующий `.dt` файл.
5. Дождитесь завершения → `Обновить конфигурацию базы данных (F7)`.
4. Выберите соответствующий `.dt` файл.
5. Дождитесь завершения → `Обновить конфигурацию базы данных (F7)`.
